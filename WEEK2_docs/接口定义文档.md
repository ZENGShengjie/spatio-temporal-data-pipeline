### 4.2 nyc_features.parquet Schema (36 列)

```
主键 (1+3)
  grid_id   : str           # nyc_gXXXX_YYYY
  datetime  : datetime64[ns]
  weekday   : int64          # 0~6
  hour      : int64          # 0~23
  month     : int64          # 6~10

时间编码 (8)
  hour_sin / hour_cos      : float32 (-1~1)
  weekday_sin / weekday_cos: float32
  month_sin / month_cos    : float32
  is_weekend               : int8 (0/1)
  is_holiday               : int8 (0/1)

空间 (6)
  dist_to_times_square / central_park / wall_street /
  grand_central / jfk_airport / city_center /
  dist_to_nearest_landmark: float32 (km)

POI (7)
  poi_food_count / poi_shopping_count / poi_entertainment_count
  poi_office_count / poi_residential_count
  poi_total_count                : int32
  poi_density_per_km2            : float32

路网 (3 + tier 4)
  road_length_m          : float32 (m)
  road_segment_count     : int32
  road_density_km_per_km2: float32
  road_len_tier_highway_m / tier_major_m / tier_minor_m / tier_local_m
                         : float32 (m)

轨迹 (2)
  taxi_pickup_count / taxi_dropoff_count : int32

气象 (5, 归一化)
  weather_temp_norm / humidity_norm / pressure_norm / wind_speed_norm / clouds_norm
                          : float32 (0~1)

卫星 (5)
  ndvi_mean / max / min  : float32
```

### 7.2 nyc_hetero_graph.pt Schema

```python
HeteroData
└── spatial : NodeData
    │   x : FloatTensor[15875, 10]   # 归一化特征
    ├── (spatial, adjacent,   spatial) : EdgeData
    │       edge_index : LongTensor[2, 127000]
    ├── (spatial, similar,    spatial) : EdgeData
    │       edge_index : LongTensor[2, 95250]
    └── (spatial, correlated, spatial) : EdgeData
            edge_index : LongTensor[2, 8482]
```

### 7.3 graph_metadata.json Schema

```json
{
  "num_nodes":          15875,

  "num_flow_edges":     8482,
```

### 7.4 节点特征列 (10 维)

`build_node_features` 聚合 14 列 → 实际 `node_feature_dim=10` 表示当前实现做了子选；如果保留全部，预期 ~14 维，对齐方法：

```python
agg_cols = [
    "dist_to_times_square", "dist_to_central_park", "dist_to_wall_street",

    "taxi_pickup_count",    "taxi_dropoff_count",
    "ndvi_mean",            "ndvi_max", "ndvi_min", "is_water",
```

注：本周输出 10 维，因为 `dist_to_city_center`、`dist_to_jfk_airport`、`ndvi_min`、`is_water` 在特征规范化处理时被多列冗余。Week 3 可调整 `agg_cols` 顺序。

## 9. 错误码与异常

每个 step 在 main 起点打印 `=====`，在尾部打印 `OK` 或 `[ERROR] ...`。

| step | 关键异常 |
|------|---------|
| step1 | `FileNotFoundError`，`pyarrow.lib.ArrowInvalid` |
| step2 | 无 fatal |
| step3 | `KeyError` 当 upstream 缺失列；`ValueError` 当 schema 不一致 |
| step4 | `RuntimeError` 当网格/特征 row 数不匹配 |

`docs/测试文档.md` 列出了对这些异常的测试断言。
