import pandera as pa

## 6. L4 — 性能测试

```python
import tracemalloc, time

def test_step1_memory_under_4GB():
    tracemalloc.start()
    t0 = time.perf_counter()
    step1.main()
    elapsed = time.perf_counter() - t0
    peak, _ = tracemalloc.get_traced_memory()
    tracemalloc.stop()

    # t3.large 8GiB 上限，step1 应 < 4 GB peak
    assert peak < 4 * 1024 ** 3
    assert elapsed < 300   # < 5 分钟
```
