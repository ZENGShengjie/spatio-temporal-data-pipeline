## 1. 审计方法

完全独立于之前生成的所有 cleaned 数据，重新从 `BJ16_M32x32_T30_InOut.h5` 出发：

1. **加载 raw H5**：`data` shape=(7220, 2, 32, 32), `date` shape=(7220,) bytes
2. **独立聚合到 hour**：`slot_1 = int(date[8:])`, `h_of_day = (slot_1 - 1) // 2`
3. **逐 hour 校验**：每个 hour = raw slot 1 + slot 2 之和
4. **填充策略**：缺失 hour 用同 day-of-week 一周前/后数据
