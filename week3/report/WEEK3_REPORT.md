# Week 3 — 北京出租车流量预测：7 个模型基线对比报告

**任务**：用过去 24 小时（48 个时间片 × 30 分钟）预测未来 24 小时北京市 32×32 网格（共 1024 格点）的人流进出总量  
**数据**：3888 个时间片 / 训练 2784h / 验证 504h / 测试 600h（Tesla T4 GPU）  
**时间**：2026 年 7 月 12 日

## 一、实验设计

### 1.1 数据

| 数据集 | 路径 | 规格 |
|--------|------|------|
| 流量数据 | `cleaned_bj/taxi_p4_4d.npz` | (3888, 2, 32, 32) float32，inflow + outflow |
| 空间图 | `graph_bj/bj_hetero_graph.pt` | PyG HeteroData，spatial + similar 两种边 |
| 时间特征 | `features_bj/bj_features.parquet` | hour_sin/cos、is_weekend、is_holiday、weather_pressure_norm |
| 网格元数据 | `grid_bj/` | 32×32 网格定义 |

**归一化**：按训练集每格历史最大值反归一化（防极值干扰）  
**目标变量**：`taxi_flow_total = inflow + outflow`

### 1.2 七模型一览

| # | 模型 | 类型 | 多步 | 核心思想 |
|---|------|------|------|----------|
| 1 | ARIMA | 经典统计 | ❌ 1次 | 每格独立 ARIMA(1,0,1)，一次性外推 600 步 |
| 2 | Prophet | 统计+季节性 | ❌ 1次 | 同上，加周周期(6) + 日周期(8)，注入 5 个外生回归量 |
| 3 | LSTM | 深度 RNN | ✅ 48步 | 2层 LSTM(h=64)，全城 2048 维向量输入，共享编码器 |
| 4 | GRU | 深度 RNN | ✅ 48步 | 同架构换 GRU 单元，轻量快速 |
| 5 | GCN | 空间图卷积 | ✅ 48步 | ST-GCN（2层）→ 每格独立 GRU → MLP 解码头 |
| 6 | GAT | 注意力图卷积 | ✅ 48步 | 同架构换 GATConv（单头，ELU 激活） |
| 7 | GRU+ST-GCN 残差 | 混合 | ✅ 48步 | Phase1 训 GRU；Phase2 冻住，ST-GCN 学残差；合成预测 |

> **1次 vs 多步说明**：ARIMA/Prophet 输出 (600, 1024)，RNN/GNN 输出 (28800, 1024)。MAE 直接对比仅供参考。

### 1.3 共同训练配置

```python

optimizer=Adam, loss=SmoothL1Loss, early_stop_patience=7

```

## 三、关键发现

### 3.1 图卷积在此数据上无效

GCN/GAT 的 MAE（~333）是 GRU（158）的 **2.1 倍**。即便经过 P1.1 V2 重构（per-timestep ST-GCN + residual + LayerNorm），改善极微（P1.1: 328.04 vs P0: 334.21）。

**原因推断**：
- 空间邻接/相似图的边权重信号太弱（相关性 < 噪声阈值）
- 1024 个格点 + 每步仅 7 维特征（2 通道 + 5 时序），GCNConv 每步传播一次即稀释殆尽
- 缺少"时间-空间"联合建模——真正可学的是"某时刻某格异常时，其邻近格在同时刻也异常"，但静态图无法表达

### 3.2 Prophet 出人意料地好

每个格独立建模（无空间信息）反而 MAE 最低（93.66），因为：
- 出租车流量的主要信号是**天周期 + 周周期**，Prophet 的季节性建模精准捕获
- 无空间传播误差累积，1次预测天然比多步滚动更稳定

### 3.3 GRU 是多步模型的甜点

- 比 LSTM 快（0.9 min vs 1.3 min），但 MAE 更低（158 vs 162）
- MAPE 43% 为全组最低，说明对高流量格点也有较好的比例控制
- Corr 0.9452 说明整体趋势拟合非常好

### 3.4 残差学习死锁

P2 混合模型训练日志：

```
[ST-Res  0] tr=0.02571  val=0.02695
[ST-Res  1] tr=0.02513  val=0.02687
[ST-Res  2] tr=0.02535  val=0.02686
[ST-Res  6] tr=0.02513  val=0.02684
[ST-Res early stop @ 13]  best_val=0.02684
```

val_loss 在 13 个 epoch 内**纹丝不动**，证明 ST-GCN 在残差上完全学不到东西，Phase-2 等效于输出常数 0。

## 四、模型实现要点

### 4.1 ARIMA（独立每格）
- `ARIMA(1,0,1)` — 1 阶自回归 + 0 阶差分 + 1 阶滑动平均
- `multiprocessing.Pool(n_jobs=min(16, cpu_count()))` 进程级并行
- 1次外推 600 步，无滚动

### 4.2 Prophet（独立每格）
- 加性季节性：weekly=6, daily=8
- 外生回归量：hour_sin, hour_cos, is_weekend, is_holiday, weather_pressure_norm
- L-BFGS 优化（Stan 内核）

### 4.3 LSTM / GRU（全城序列）
- 输入：(B, T_seq=48, F_in=2048+K_time=5)
- 2层 RNN → 末状态 → FC(64 → 48×1024) → reshape(B, 48, 1024)
- **同一隐状态在 1024 格间共享**，适合捕获全市宏观时序模式

### 4.4 GCN / GAT（时空图）
- 每步先做空间聚合：`(B, T, N, F=2+K)` → 逐时间片过 GCNConv/GATConv → concat + fuse + LayerNorm + 残差
- 2层 ST-Block 后 flatten → 每格独立 GRU 串时间 → LayerNorm → MLP 解码头
- 边类型：spatial（邻接）+ similar（流量相似性），correlated 边因 NaN 被剔除

### 4.5 GRU+ST-GCN 残差（混合）
- Phase1：训标准 GRU，checkpoint 后冻结
- Phase2：在归一化空间训练 ST-GCN，目标为 `y - gru_pred`
- Phase3：合成 `final = gru_pred_norm + stgcn_residual_norm`，统一反归一化

## 八、Week3 基线局限性分析

> 本节系统梳理 Week3 七模型基线的核心瓶颈，为 Week4 时空建模提供明确的问题导向。

### 8.1 传统统计模型（ARIMA/Prophet）的预测范式局限

**核心问题：1-shot 预测 vs 滑动窗口多步预测，口径不可比**

ARIMA 和 Prophet 的预测逻辑与深度学习模型有本质区别：

| 维度 | ARIMA / Prophet | LSTM / GRU / GCN / GAT |
|------|----------------|----------------------|
| 求解方式 | 最小二乘 / 极大似然一次性求解 | 反向传播多轮迭代 |
| 预测方式 | 一次性输出 600 步，后续步基于真实值递推 | 48 步滚动，每步输入含上步预测（误差累积） |
| 空间建模 | 每格独立，完全无空间信息 | 支持图结构 / 全连接 |
| 周期建模 | Prophet 有加性季节性（周+日）| 隐式学习，无显式约束 |
| MAE 可比性 | ⚠️ 口径不同，不可直接比较 | ✅ 同口径可比 |

**具体局限**：
- **ARIMA(1,0,1)**：强假设数据平稳，对北京出租车流量这类强周期性、非平稳信号表达能力有限。MAE=154.76 部分源于模型假设与数据特性的根本性冲突
- **Prophet**：周周期(6) + 日周期(8) 捕捉了出租车流量的主要规律，MAE=93.66 看似最优，但这是因为 1-shot 预测不存在误差累积，且独立预测每格时，空间信息完全丢失

### 8.2 时序卷积不如 GRU——感受野与门控机制的双重缺失

**核心问题：CNN 感受野固定、无记忆门控，无法捕获长程周期**

| 问题 | 具体表现 |
|------|---------|
| 感受野有上限 | Conv1d(kernel=3, layers=5) 只能看 11 个时间步，远小于 48 步输入；24h 周期需要 48 步，Conv 完全覆盖不到 |
| 无门控机制 | 低流量凌晨时段流量接近 0，Conv 对噪声无过滤能力；GRU 的 reset gate 可以主动遗忘噪声 |
| 多步误差放大 | Conv 的固定卷积核在每一步产生固定误差，多步后误差线性累积；GRU 的 hidden state 提供了隐式记忆 |

Week3 实验验证了这一点：LSTM(MAE=162) 优于所有基于 Conv 的方案，说明对于 48 步多步预测任务，**门控机制比卷积核的非线性表达能力更重要**。

### 8.3 GCN/GAT 的图卷积在此数据上完全失效

**核心问题：静态邻接图无法建模动态通勤关系，反而引入噪声**

Week3 中 GCN(MAE=332) 和 GAT(MAE=334) 的表现是 GRU(MAE=158) 的 **2.1 倍差距**，P2 残差实验中 ST-GCN 完全学不到东西（val_loss 纹丝不动）。

| 问题 | 具体表现 |
|------|---------|
| 图结构是静态的 | 北京五环内 1024 个格子用地理邻接定义边，但出租车从望京去通州是直接到达，不是逐格传播 |
| 早高峰≠深夜 | 固定图无法区分"早上商业区→居民区"的通勤流和"深夜娱乐区→全城发散"的打车流 |
| 特征维度不足 | 每格每步仅 7 维（inflow + outflow + 5 维时序特征），GCNConv 一次空间聚合后信息被严重稀释 |
| 缺少时空联合 | GCN 聚合空间后接独立 GRU，是**先空间后时间**的串联；真正的时空建模需要每步同时考虑空间和时间依赖 |

**Week4 的突破方向**：STGCN 的三明治结构（空间→时间→空间→时间）和 STF 的时空分离设计，都是对 Week3 串联架构的改进。

### 8.4 残差学习为何死锁——双分支训练的优化困境

P2 GRU+ST-GCN 残差实验中，ST-GCN 的 val_loss 在 13 个 epoch 内完全不动：

```
[ST-Res  0] tr=0.02571  val=0.02695
[ST-Res  6] tr=0.02513  val=0.02684   ← 纹丝不动
[ST-Res early stop @ 13]  best_val=0.02684
```

根因分析：
1. **冻结 GRU 已经占据了最优预测空间**：GRU 的 MAE=158.12 已经是强基准，残差分支只能在极小的误差空间内工作，信噪比极低
2. **双分支超参数未联合调优**：ST-GCN 的学习率、LayerNorm 位置、dropout 等参数均未针对残差场景重新设计
3. **固定图卷积提供的是噪声而非信号**：即使 ST-GCN 学到了东西，也是被 GRU 漏掉的噪声，而非有意义的额外信息

这说明：**在已有强时序基线的情况下，引入图卷积不能靠简单的残差叠加，需要重新设计联合训练目标或完全替换架构**。

### 8.5 结论：Week3 的核心瓶颈是空间建模

Week3 七模型基线的核心教训：

| 模型 | 瓶颈 | 突破方向 |
|------|------|---------|
| ARIMA/Prophet | 无空间建模能力 | — |
| LSTM/GRU | 无空间建模能力 | 引入图结构 |
| GCN/GAT | 固定静态图引入噪声 | 自适应图 / 时空联合建模 |
| GRU+GCN 残差 | 双分支训练死锁 | 重新设计联合训练 |

**Week4 正是针对以上瓶颈的系统性突破**：STF 用时空解耦替代串联、AGFormer 用自适应图替代静态图、STGCN 用三明治结构替代先空后时。
