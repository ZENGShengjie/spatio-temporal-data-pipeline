项目概述

问题

城市异常事件（活动 / 灾害 / 事故）发生时，
需要实时检测并提前预警。

输入

北京出租车 GPS (30min × 32×32 网格)
+ 气象 + POI + OSM 路网

输出

1024 网格 × 600 时间步异常标签
+ 48h 未来流量预测
+ 可解释性归因

形态

FastAPI + Streamlit 一键部署

业务场景

  • 1 大型活动预警：演唱会 / 赛事散场 → 网格流量突增 → 提前 30min 推送
  • 2 恶劣天气响应：暴雨 / 高温 / 寒潮 → 流量骤降 → 辅助公交调度
  • 3 交通事故检测：局部流量异常聚集 → 联动 110 / 122
  • 4 节假日感知：春节 / 清明 → 推断异常类型 + 流量模式

业务方：北京市交通管理 / 大型园区 / 连锁零售 (选址与人流监测)

技术难点（4 大坑 + 解法）

#问题影响解法
1 异常注入失真 (0.03% < 4%) F1 < 0.1，所有模型失效 按比例反向计算 + 强制校验
2 STF 权重加载失败（路径漂移） 预测法退化为恒零 重写推理链路 + ckpt 结构兼容
3 融合权重搜索空间爆炸 O(n⁴) 训练成本不可承受 分阶段：先搜阈值再搜权重 → O(n²)
4 小数据集下大模型过拟合 AGFormer MAE 比 STF 高 18% 时空分解 + 环境 token → 222K

小结

  • STF 在 1 个 epoch 后即收敛（时空分解快速收敛）
  • AGFormer 训练 29 epoch 才到最优，且 MAE 比 STF 高 18%
  • 消融：移除 Env Token + 跨节点注意力 → MAE +2.2%

四范式异常检测

范式原理优点局限
统计阈值3σ + IQR 分时段无需训练、可解释难捕获复杂模式
预测误差STF 预测残差捕获非线性偏离依赖模型精度
VAE单网格重构学习流形结构GAN-style 训练不稳
Transformer AE多网格掩码重构捕获双向上下文需更多数据

可解释性分析

SHAP Top 特征

  • target_grid_in: 0.0196 历史同期
  • hour: 日内周期
  • day_of_week: 周周期
  • POI 密度: 功能区划
  • 温度: 极端天气

注意力头分工

  • H0: 局部邻居 (低方差)
  • H1: 长程依赖 (方差高 2.4×)
  • 早高峰: 关注前一天同时段
